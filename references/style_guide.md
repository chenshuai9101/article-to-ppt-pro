# 文章转PPT增强版 - 排版规范指南

## 一、中文排版基础

### 1.1 字体规范

| 元素 | 推荐字体 | 备选字体 |
|------|---------|---------|
| 标题 | 黑体 / 微软雅黑 | 方正黑体 |
| 正文 | 宋体 / 微软雅黑 | 系统默认 |
| 英文/数字 | Arial / Helvetica | Times New Roman |

### 1.2 字号规范

| 元素 | 字号范围 | 推荐值 |
|------|---------|--------|
| 封面标题 | 36-48pt | 44pt |
| 章节标题 | 24-32pt | 28pt |
| 正文标题 | 18-24pt | 20pt |
| 正文内容 | 14-18pt | 16pt |
| 注释/备注 | 10-12pt | 12pt |

### 1.3 行距规范

| 内容类型 | 行距 | 说明 |
|---------|------|------|
| 标题 | 1.0-1.2倍 | 紧凑排列 |
| 正文 | 1.2-1.5倍 | 舒适阅读 |
| 要点列表 | 1.5倍 | 充分留白 |

## 二、中文标点规范

### 2.1 标点使用

- 句号：`。`
- 逗号：`，`
- 顿号：`、`
- 分号：`；`
- 冒号：`：`
- 引号：`「」` 或 `""`
- 括号：`（）`

### 2.2 标点禁则

- 不允许出现半角标点与全角标点混用
- 避免连续使用三个以上相同标点
- 省略号使用`……`，不使用`...`

## 三、段落排版

### 3.1 首行缩进

- 中文段落：首行缩进2字符
- 英文段落：首行不缩进
- 特殊排版：可使用首行悬挂

### 3.2 段落间距

- 段前间距：0-0.5行
- 段后间距：0.5-1行
- 避免过大间距造成视觉断裂

## 四、重点内容标注

### 4.1 高亮方式

| 方式 | 适用场景 | 示例 |
|------|---------|------|
| 加粗 | 关键词强调 | **核心成果** |
| 颜色 | 分类标注 | 数据使用蓝色 |
| 底色 | 重要提示 | 背景高亮 |

### 4.2 层级关系

```
一级：标题（最大字号，加粗）
二级：副标题（中等字号，加粗）
三级：小标题（标准字号，加粗）
四级：正文（标准字号，不加粗）
```

## 五、信息密度控制

### 5.1 每页字数建议

| 页码类型 | 字数范围 | 说明 |
|---------|---------|------|
| 封面 | 10-20字 | 标题+副标题 |
| 目录 | 20-40字 | 章节列表 |
| 内容页 | 100-300字 | 核心要点 |
| 数据页 | 50-100字 | 图表说明 |
| 结尾 | 5-10字 | 感谢语 |

### 5.2 要点数量

- 每页要点：3-5个
- 每点字数：15-30字
- 超过5点考虑分页

## 六、对齐规范

### 6.1 标题对齐

| 标题类型 | 对齐方式 |
|---------|---------|
| 封面标题 | 居中 |
| 章节标题 | 左对齐 |
| 图注说明 | 居中或右对齐 |

### 6.2 内容对齐

- 正文：左对齐或两端对齐
- 列表：左对齐
- 数据：右对齐或居中
- 表格：居中

## 七、配色方案

### 7.1 职场通用配色

```
主色：#2563EB（蓝色）
辅色：#3B82F6（浅蓝）
背景：#FFFFFF（白色）
文字：#1F2937（深灰）
强调：#F59E0B（橙色）
```

### 7.2 配色原则

- 背景与文字对比度 > 4.5:1
- 避免使用过多颜色（不超过4种）
- 重要信息使用主色强调
- 次要信息使用灰色

## 八、图表规范

### 8.1 数据图表

- 柱状图：用于对比
- 折线图：用于趋势
- 饼图：用于占比
- 表格：用于详细数据

### 8.2 图表样式

- 标题清晰
- 刻度标注
- 图例说明
- 数据来源

## 九、模板样式指南

### 9.1 投资人汇报模板

- 风格：专业商务
- 配色：蓝白为主
- 重点：数据图表突出
- 布局：左右分栏为主

### 9.2 述职报告模板

- 风格：简洁商务
- 配色：深灰+白色
- 重点：成果量化展示
- 布局：上下分区为主

### 9.3 项目总结模板

- 风格：结构清晰
- 配色：绿白为主
- 重点：时间线展示
- 布局：卡片式布局

### 9.4 培训课件模板

- 风格：循序渐进
- 配色：紫色系
- 重点：要点明确
- 布局：左右图解
